# Support

Quorra is a personal developer tool maintained on a best-effort basis.

Use [GitHub Issues](https://github.com/ajbeck/quorra/issues) for reproducible
bugs and concrete feature requests. Before opening an issue, search existing
issues and include the Quorra version, macOS version, steps to reproduce, and
any relevant non-sensitive logs.

Do not include AWS access keys, session tokens, AWS configuration contents, or
other credentials in an issue. Report security vulnerabilities privately as
described in [SECURITY.md](SECURITY.md).
